## Compatibility

These are the wrapper-based v1 APIs. Install packages pinned to major **1**, and keep legacy declarations/CLI 1 with a v1 application. Do not mix v1 consumers with a Node v2 bootstrap snapshot.

React Native, OpenFeature and Management have their own supported contracts; they are not upgraded by this selector. Product guides remain shared rather than duplicated into this version.
